# シサミル

パチスロの設定示唆・演出をすぐ引ける早見帳です。名前は「示唆を見る」から。画面上の機種名をタップすると、プルダウンで機種を切り替えられます。

## 収録している機種

- L青春ブタ野郎はバニーガール先輩の夢を見ない（青ブタ）
- スマスロ とある魔術の禁書目録２
- L戦国乙女5 業火を穿つ宿焔の双刃
- Lパチスロ 革命機ヴァルヴレイヴ2
- パチスロ 革命機ヴァルヴレイヴ
- スマスロ リコリス・リコイル
- スマスロ モンスターハンターライズ：サンブレイク
- スロット ソードアート・オンラインⅡ
- スマスロ パリピ孔明
- スマスロ ミリオンゴッド-神々の軌跡-

## 使うURL

https://applicationsvell.github.io/slotlist/

## ホーム画面に追加する

- iPhone：Safariで上のURLを開く →「共有」→「ホーム画面に追加」
- Android：Chromeで開く → 右上のメニュー →「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面のアイコンから開くと、全画面のアプリとして動きます。一度開けば、電波が弱いホールの中でも見られます。新しい内容は、電波があるときに開き直すと入ります。

## 画像の出典

画面写真は [一撃（1geki）の青ブタ解析ページ](https://1geki.jp/slot/l_ao_buta/) から、出典リンクを付けて引用しています。ちょんぼりすた・なな徹はリンクのみで、画像は使っていません。

## 開発メモ

- `src/page.html`：ページの本体（見た目と動き）。claude.ai のアーティファクト版もこのファイルから公開する（`machines/` と `img/` を一緒に送る）
- `machines/<機種>.js`：機種ごとの示唆データ。タブ・項目・写真をここに書く。新しい機種はファイルを足して、`src/page.html` の `<script src="machines/…">` の並びに1行足す
- `img/<機種>/`：一撃から引用した画面写真（webp）
- 見た目：上の看板は機種ごとの色（機種ファイルの `color: { a, b, ink }`。a が下・b が上の色、`ink: 'dark'` で文字を紺に）。ダークモードの色は自動で夜の色に寄せる。設定判別は、ホールのデータカウンター風の電光表示で、設定ごとの柱は示唆の色と同じ順（設定2は青、3は黄、4は赤、5は紫、6は虹）
- 設定判別ツール：機種ファイルに `judge`（`settings`・`rates`・`pairs`・`memo`・`cautions`）を書くと、その機種に「設定判別ツール」ボタンが出る。いまは全10機種。数値は一撃の設定差・設定判別ツールのページから
  - `settings`：候補にする設定（例：ヴァルヴレイヴ2は `[1, 2, 4, 5, 6]`）
  - `rates`：通常時のゲーム数に対する回数（値は分母）。いちばん大事な初当りは `id: 'hit'` にする（最初から計算に入る）
  - `pairs`：引いた回数とそこから当たった回数（値は%）。当たり方が複数あるときは `outs: [{ b, p }, …]`
  - 「設定示唆」タブの示唆は、結果の文言（○以上濃厚・2・4・6濃厚・偶数濃厚・奇数・偶数・高設定示唆（弱・中・強）・否定）から重みを自動で決める。出現率がわかっている示唆は項目に `w: [設定ごとの値]` を書くとその値を使う。色の札（`lv`）がない項目でも `count: true` を付けると＋1で数えられる（「設定2を否定」など）
  - `memo` に書いたグループはモード示唆として回数だけ数え、計算には入れない
  - `wt`：ほかの要素と一部重なるもの（青ブタのCZ最終ゲームと初当りなど）は、重みを下げて掛け合わせる（0.5なら半分）。`skipIf`：同じ当たりを別の数え方で数えているとき（アオハルの回数と「チェリー → アオハル」）は、その率を外す。`pairs` も `sec` で区分のカードに入れられる
  - 最初の見込み：「均等」（どの設定も同じ）・「ふだん」（1つ上がるごとに0.6倍）・「高設定狙い」（1つ下がるごとに0.75倍）を選べる。端末に保存
  - `rates` の `per`：`'normal'`（通常時のゲーム数で割る・いつもはこれ）、`'all'`（通常時＋AT中のゲーム数。通常時もAT中も同じ確率の小役など）、`'at'`（AT中のゲーム数）。`'all'`・`'at'` があると「AT中に数えるもの」とAT中のゲーム数の欄が出る
  - `marks`：設定1（青ブタは設定2、`bs` で指定）の値しかわからないもの。計算には入れず、その値より良いか悪いかの「目安」だけ出す（`kind: 'pair'` は引いた回数と当たった回数、`base` は設定1の値）
  - 有利区間：差枚は「持ち玉−投資枚数」（投資枚数＝投資金額÷1000×1000円で借りられる枚数。ふだんは46枚）で出す（データカウンターの差枚を直接入れることもできる）。スマスロ・6.5号機の上限は、有利区間が始まったときの差枚から＋2400枚なので「2400−（いまの差枚−始まったときの差枚）」が残り。切れたら記録して、そこから数え直す
  - `yuri`：機種ごとの有利区間の情報。`notes`（いつ切れるか・切れたあとの恩恵）、`src`（出典）、`end`（エンディングに入る差枚。サンブレイクは2200枚）、`cap`（上限。ふだんは2400枚）
  - 記録は機種ごとに1台ぶん、端末（localStorage）に保存する
- `node src/build-app.js`：`src/page.html` から、ルートの `index.html`・`manifest.webmanifest`・`sw.js` と `machines/dims.js`（写真の縦横）を作り直す。ページ・データ・画像を変えたら必ず実行する（`sw.js` の版が変わり、アプリに新しい内容が届く）
- アプリ版では、開いた機種の写真をその場で端末に保存する（全機種ぶんを最初に落とすと重いため）
- `node src/icon.js`：`icons/` のアイコンを作り直す（Playwright が必要）
- アプリ版では `window.APP_MODE` が true になる。アーティファクト版との違いは「台の情報」の案内文と、時計などの帯の色だけ
- 公開は GitHub Pages（Settings → Pages → Deploy from a branch）
